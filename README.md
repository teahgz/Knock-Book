## 🎯 프로젝트 소개
모든 연령층이 즐길 수 있는 소통 중심의 독서 커뮤니티 플랫폼입니다. Servlet/JSP를 활용하여 사용자 간의 활발한 소통과 참여를 증진시키는 다양한 기능을 제공합니다.

## 💡 주요 기능

### 1. 사용자 관리
- 회원가입 및 로그인
- 사용자 프로필 관리

### 2. 독서 활동
- 독서 신청
- 독후감 작성
- 독후감 좋아요 기능

### 3. 이벤트 관리
- 이벤트 작성 및 신청
- 이벤트 참여 관리
- 이벤트 댓글/대댓글 시스템

### 4. 커뮤니티 기능
- 독후감 및 이벤트 댓글/대댓글
  - AJAX를 활용한 비동기 댓글 처리
  - 계층형 댓글 구조 구현
  - 세션 기반 사용자 권한 관리
- 문의사항 관리
  - 기본 답변 템플릿 제공
  - 관리자 전용 페이지 접근 제어
  - 파일 업로드 및 이미지 미리보기 기능

## 📝 프로젝트 성과

### 기술적 성과
- **URL 매핑의 중요성 인식**
  - 이미지 파일 처리와 서버 설정의 상관관계 이해
  - web.xml 설정을 통한 효율적인 리소스 관리 경험
- **계층형 데이터 구조 설계**
  - 댓글-대댓글 간 관계 설계 및 구현
  - 효율적인 데이터베이스 구조 설계 경험
- **비동기 통신 활용**
  - AJAX를 통한 실시간 댓글 시스템 구현
  - 사용자 경험 향상을 위한 비동기 처리 구현

### 팀 협업 성과
- **효율적인 의사소통**
  - 정기적인 회의를 통한 진행 상황 공유
  - 문제 해결을 위한 팀원 간 적극적인 소통
- **팀워크 향상**
  - 각자의 의견을 존중하는 문화 형성
  - 협업을 통한 문제 해결 능력 향상
